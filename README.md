
# ShhhQL 🤫
### We take data leaks personally. Literally.

ShhhQL is a MySQL Privacy Engineering Toolkit designed to help identify sensitive data, assess exposure risks, and verify database protection controls.

## Objectives

- Discover and classify personal data in MySQL databases.
- Assess data exposure risks.
- Support data protection through encryption, masking, and access controls.
- Verify backup and recovery security.
- Measure security and performance before and after protection.

## Technology Stack

- Python
- Flask
- MySQL
- HTML, CSS, and JavaScript

## Security Notice

- Use synthetic data in development and testing.
- Never commit database passwords, encryption keys, or active credentials.
- Do not upload database dumps containing personal information.
- Validate every security control through reproducible tests.
